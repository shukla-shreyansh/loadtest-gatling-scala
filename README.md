# Gatling Scala Based Load Testing Framework

## Overview
This load testing framework is designed to comprehensively evaluate the performance and scalability of a platform using Gatling, Scala, and other testing methodologies.

## 📋 Prerequisites

### System Requirements
- Java Development Kit (JDK) 11 or later
- Scala 2.13.x
- SBT 1.5.x or later

### Installation Steps
1. Clone the repository

2. Install Dependencies
   ```bash
   sbt update
   ```

## 🛠 Configuration

### Environment Configuration
Edit `src/main/resources/gatling.conf` to customize:
- Load testing scenarios
- Performance thresholds
- Environment settings

Example Configuration:
```hocon
load-test {
  scenario {
    max-concurrent-users = 5000
    ramp-up-duration = 30
    test-duration = 10
  }
  
  performance {
    max-response-time-ms = 500
    success-rate-threshold = 0.99
  }
}
```

## 🧪 Running Load Tests

### Local Testing
```bash
# Run all simulations
sbt gatling:test

# Run specific simulation
sbt "gatling:testOnly simulations.LoadSimulation"
```

### Test Data Generation
```bash
# Generate user and content test data
sbt "run-main feeders.UserDataFeederApp"
sbt "run-main feeders.ContentDataFeederApp"
```
